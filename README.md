# BAK-Blog

A modern and user-friendly blogging platform built using the MERN stack, designed to streamline content creation and management.

## Features
- **Dynamic User Dashboard:** Manage blog posts effortlessly.
- **Secure Authentication:** User login and registration powered by JSON Web Token (JWT).
- **Comprehensive CRUD Operations:** Efficiently handle blog posts with MongoDB.
- **State Management:** Utilized Redux Toolkit for seamless data flow.
- **Responsive Design:** Fully responsive layout ensuring a great experience on any device.

## Tech Stack
- **Frontend:** React.js, Redux Toolkit
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Other Tools:** JWT, RESTful APIs
