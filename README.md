# BAK-Blog

A comprehensive blogging platform built using the MERN stack, featuring a modern user dashboard, secure authentication, and seamless CRUD operations.

## Features
- User-friendly dashboard for managing blog posts.
- Secure authentication using JSON Web Token (JWT).
- Optimized CRUD operations with MongoDB database.
- State management with Redux Toolkit for a smooth user experience.

## Tech Stack
- **Frontend**: React.js, Redux Toolkit
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Other Tools**: JWT, RESTful APIs
